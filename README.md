# JavaFX Basic Calculator

## Overview

This project is a basic calculator built using Java and JavaFX. It provides a graphical user interface where users can enter numbers and perform basic arithmetic operations.

I created this project to practice Java programming, learn JavaFX, and gain experience building desktop applications with a graphical user interface.

## Features

- Graphical user interface built with JavaFX
- Addition, subtraction, multiplication, and division
- Support for multiple-digit numbers
- Decimal number input
- Clear button to reset the calculator
- Display for showing numbers and calculation results
- Error handling for division by zero

## Technologies Used

- **Java** — Calculator logic and application functionality
- **JavaFX** — Graphical user interface
- **FXML** — Interface layout and button configuration
- **Maven** — Dependency management and project building
- **Git and GitHub** — Version control and project hosting

## How to Run

### Prerequisites

- Java Development Kit (JDK)
- Apache Maven
- JavaFX dependencies configured through Maven

### Steps

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate into the project directory:

   ```bash
   cd <your-project-folder>
   ```

3. Run the application:

   ```bash
   mvn javafx:run
   ```

## How to Use

1. Click the number buttons to enter a number.
2. Select an arithmetic operator (`+`, `-`, `*`, or `/`).
3. Enter the second number.
4. Press `=` to calculate the result.
5. Press `C` to clear the display and start over.
